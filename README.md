# TNVED_BOT

Telegram-бот, который подбирает 10-значный код ТН ВЭД ЕАЭС по текстовому описанию товара или
по фотографии. Работает локально на Windows, использует ИИ через CLI `claude -p`.

**Ключевая гарантия:** ИИ не изобретает коды. Кандидаты берутся из локального официального
справочника, и каждый код перед отправкой пользователю сверяется с базой.

> ⚠️ Бот носит справочный характер. Окончательное решение о классификации принимает декларант;
> для официальной позиции — предварительное решение ФТС.

## Требования

- Windows 10/11
- Python 3.12+ (проверено на 3.14)
- Claude Code CLI в PATH, авторизованный (`claude --version`)
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- Файл официального справочника ТН ВЭД ЕАЭС (CSV или XLSX)

## Установка

```powershell
cd c:\Claude\TNVED_BOT

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Copy-Item .env.example .env
# заполнить BOT_TOKEN и ADMIN_USER_IDS в .env
```

`ADMIN_USER_IDS` — только администраторы, через запятую без пробелов. Свой Telegram ID можно
узнать, написав боту: он вернёт ID в сообщении об отказе в доступе.

### Как добавить остальных пользователей

Их **не нужно** вписывать в `.env` — список живёт в базе и меняется без перезапуска:

```text
/invite Петров          → бот вернёт код вида TNVED-7K2M-9XQP (действует 24 часа)
```

Пересылаете код человеку, он отправляет боту `/start TNVED-7K2M-9XQP` — и доступ есть.
Так не приходится объяснять, где искать свой Telegram ID.

Если ID известен заранее — `/adduser 123456789 Петров, отдел ВЭД`.
Отозвать — `/deluser 123456789`. Посмотреть список — `/users`.

## Загрузка справочника ТН ВЭД

```powershell
# положить файл справочника в data\nomenclature\
python scripts\import_nomenclature.py data\nomenclature\tnved.csv
```

До загрузки справочника бот стартует, но на запросы отвечает «справочник не загружен».
Откат к предыдущей версии: `python scripts\import_nomenclature.py --rollback`.

## Запуск

```powershell
.\.venv\Scripts\Activate.ps1
python -m tnved_bot
```

Остановка — `Ctrl+C`.

## Автозапуск при включении компьютера

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1
```

Регистрирует задачу `TNVED_BOT` в Планировщике заданий: запуск при входе в систему,
перезапуск при падении (3 попытки × 1 мин), без остановки по таймауту.

Удаление: `powershell -ExecutionPolicy Bypass -File scripts\uninstall_autostart.ps1`

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/start <код>` | Активировать приглашение |
| `/help` | Как описывать товар, что влияет на код |
| `/cancel` | Прервать текущие уточнения |
| `/code <10 цифр>` | Официальное наименование кода из справочника |
| `/forget` | Удалить все свои фото и сессии немедленно |
| `/version` | Версия бота и справочника |
| `/users` | Список пользователей (администратор) |
| `/adduser <id> [заметка]` | Выдать доступ (администратор) |
| `/deluser <id>` | Отозвать доступ (администратор) |
| `/invite [заметка]` | Код приглашения на 24 ч (администратор) |
| `/health` | Статус системы (администратор) |
| `/stats` | Статистика за сутки (администратор) |
| `/reload_db` | Перечитать справочник (администратор) |

## Приватность

- Доступ только по whitelist: администраторы из `ADMIN_USER_IDS`, остальные — из таблицы
  `allowed_users`, добавленные вручную или по одноразовому коду приглашения.
- Фотографии хранятся локально **не более 48 часов**, затем удаляются автоматически.
- Фото не передаются никуда, кроме локального процесса `claude`.
- Полные тексты запросов не логируются — только SHA-256.
- Команда `/forget` удаляет данные пользователя немедленно.

## Диагностика

| Симптом | Причина и решение |
|---|---|
| Бот не отвечает | Проверить `logs/bot.log`; проверить, что задача `TNVED_BOT` запущена |
| «Справочник не загружен» | Выполнить `scripts\import_nomenclature.py` |
| «ИИ временно недоступен» | Проверить `claude --version` и авторизацию Claude Code |
| Бот отвечает медленно | Одновременно выполняется другой запрос (лимит 2); дождаться очереди |
| Не стартует после перезагрузки | `Get-ScheduledTask -TaskName TNVED_BOT`; проверить `logs/stdout.log` |
| «Диалог уже закрыт» | Сессия истекла (30 мин) — отправить запрос заново |
