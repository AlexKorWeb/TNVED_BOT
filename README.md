# TNVED_BOT

Telegram-бот, который подбирает 10-значный код ТН ВЭД ЕАЭС по текстовому описанию товара или
по фотографии. Работает локально на Windows, обращается к ИИ через CLI `claude -p`.

**Ключевая гарантия:** ИИ не изобретает коды. Кандидаты берутся из локального справочника,
модель выбирает **только из них**, и каждый код перед отправкой пользователю сверяется с базой.
Код, которого нет в активной версии справочника, физически не может попасть в ответ.

> ⚠️ Бот носит справочный характер. Окончательное решение о классификации принимает декларант;
> для официальной позиции — предварительное решение ФТС.

- Техническое задание: [docs/TZ.md](docs/TZ.md)
- Тикеты и отчёты: [docs/tasklist/tickets.md](docs/tasklist/tickets.md)
- Правила разработки: [CLAUDE.md](CLAUDE.md), [conventions.md](conventions.md)

## Что умеет

| Возможность | Как работает |
|---|---|
| Код по описанию | Два обращения к ИИ: перевод запроса на язык справочника, затем выбор из кандидатов |
| Код по фотографии | Модель описывает товар, вы подтверждаете описание, дальше обычный пайплайн |
| Уточняющие вопросы | Кнопками, до 3 раундов; при неуверенности бот спрашивает, а не гадает |
| Управление доступом | Whitelist в БД + одноразовые коды приглашений |
| Автозапуск | Задача планировщика при входе в систему + надзорный перезапуск |
| Автоудаление фото | 48 часов, включая догоняющую очистку после простоя компьютера |

## Требования

- Windows 10/11, Python 3.12 (проверено на 3.12.10)
- Claude Code CLI в PATH и авторизованный (`claude --version`)
- Токен бота от [@BotFather](https://t.me/BotFather)
- Файл справочника ТН ВЭД ЕАЭС (XLSX или CSV) — см. ниже

## Установка

```powershell
cd c:\Claude\TNVED_BOT

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .

Copy-Item .env.example .env
# заполнить BOT_TOKEN и ADMIN_USER_IDS
```

`ADMIN_USER_IDS` — числовые Telegram ID администраторов через запятую, без пробелов. Свой ID
можно узнать, написав боту: он вернёт его в сообщении об отказе в доступе.

## Загрузка справочника

Скачайте актуальную выгрузку и импортируйте:

```powershell
Invoke-WebRequest -Uri 'https://www.tws.by/tws/tnved/download/excel' `
  -OutFile "data\nomenclature\tnved_$(Get-Date -Format 'yyyy-MM-dd').xlsx"

python scripts\import_nomenclature.py "data\nomenclature\tnved_$(Get-Date -Format 'yyyy-MM-dd').xlsx"
```

Импорт атомарен: пока новая версия не записана целиком, активной остаётся прежняя.
Откат — `--rollback`, список версий — `--list`. Разбор источника и его ограничения:
[docs/research/nomenclature-sources.md](docs/research/nomenclature-sources.md).

До загрузки справочника бот стартует, но на запросы отвечает «справочник не загружен».

## Запуск

```powershell
python -m tnved_bot          # вручную, Ctrl+C для остановки
```

### Автозапуск при включении компьютера

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1
```

Создаёт задачу `TNVED_BOT`: запуск при входе в систему, скрытое окно, без ограничения времени
работы. Перезапуск после падения делает надзорный цикл в `scripts\run_bot.ps1` — проверено, что
встроенный механизм планировщика в этом сценарии не срабатывает.

```powershell
Start-ScheduledTask -TaskName TNVED_BOT                  # запустить сейчас
powershell -File scripts\stop_bot.ps1                    # остановить
powershell -File scripts\uninstall_autostart.ps1         # убрать автозапуск
python scripts\smoke_check.py                            # проверить состояние
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/start <код>` | Активировать приглашение |
| `/help` | Как описывать товар, чтобы код был точным |
| `/code <10 цифр>` | Официальное наименование кода из справочника |
| `/cancel` | Прервать текущие уточнения |
| `/forget` | Немедленно удалить свои фото и диалоги |
| `/version` | Версия бота и справочника |

Администраторам дополнительно:

| Команда | Что делает |
|---|---|
| `/users` | Список пользователей с заметками |
| `/adduser <id> [заметка]` | Выдать доступ без перезапуска |
| `/deluser <id>` | Отозвать доступ, закрыть активные диалоги |
| `/invite [заметка]` | Одноразовый код приглашения на 24 часа |
| `/health` | Справочник, `claude`, диск, очередь |
| `/stats` | Статистика за сутки |
| `/reload_db` | Сведения об активной версии справочника |

### Как пригласить человека

Спрашивать у него Telegram ID неудобно — он обычно не знает, где его взять:

```text
/invite Петров        →  TNVED-7K2M-9XQP
```

Перешлите код; человек отправляет боту `/start TNVED-7K2M-9XQP` и получает доступ. Код
одноразовый и живёт 24 часа, вы получите уведомление с ID активировавшего.

## Приватность

- Доступ только по whitelist: администраторы из `.env`, остальные — в таблице `allowed_users`.
- Фотографии хранятся локально **не более 48 часов**, затем файлы удаляются с диска.
- При сохранении фото пересохраняется в JPEG — это уничтожает EXIF, включая геолокацию съёмки.
- Фото не передаются никуда, кроме локального процесса `claude`.
- Полные тексты запросов в журнал не пишутся — только SHA-256.
- `/forget` удаляет данные пользователя немедленно, не дожидаясь TTL.

## Диагностика

| Симптом | Причина и решение |
|---|---|
| Бот не отвечает | `python scripts\smoke_check.py`; смотреть `logs\bot.log` |
| «Справочник не загружен» | Выполнить `scripts\import_nomenclature.py` |
| «ИИ временно недоступен» | Проверить `claude --version` и авторизацию Claude Code |
| Ответ идёт 15–20 секунд | Нормально: два обращения к ИИ. Норматив ТЗ — до 60 с |
| Бот отвечает дважды | Запущено два экземпляра: `scripts\stop_bot.ps1`, затем один запуск |
| Не стартует после перезагрузки | `Get-ScheduledTask -TaskName TNVED_BOT`; смотреть `logs\stdout.log` |
| «Диалог уже закрыт» | Сессия истекла (30 мин) — отправьте запрос заново |
| Скрипт `.ps1` падает на разборе | Файл сохранён без BOM: PowerShell 5.1 читает `.ps1` как ANSI |
