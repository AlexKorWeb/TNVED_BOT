# /plan — план реализации

Вызови агента `planner` для активного тикета.

1. Передай агенту: тикет, PRD, отчёт research, релевантные разделы `docs/TZ.md`.
2. Агент создаёт `docs/plan/<ticket-id>.md` с разделами: решение по слоям, контракты,
   обработка ошибок, безопасность, шаги реализации, тесты, вне объёма.
3. Покажи пользователю краткое резюме плана и ключевые архитектурные развилки с рекомендацией.
4. **Останови работу и дождись подтверждения.** Без явного «ок» переходить к `/implement` нельзя.

Никакого кода на этом шаге.

Следующий шаг после подтверждения: `/implement`.
