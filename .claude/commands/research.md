# /research — исследование кодовой базы

Вызови агента `researcher` для активного тикета.

1. Прочитай `docs/.active_ticket` и PRD (`docs/prd/<ticket-id>.md`), если он есть.
2. Агент собирает факты в `docs/research/<ticket-id>.md`: какие файлы затрагиваются,
   кто их импортирует, какие тесты уже есть и каков их текущий результат.
3. **Обязательно** убедись, что агент реально прогнал существующие тесты по затрагиваемому коду
   и приложил вывод — а не предположил, что тестов нет.

Ничего не менять в исходниках.

Следующий шаг: `/plan`.
