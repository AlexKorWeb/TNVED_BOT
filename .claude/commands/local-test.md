# /local-test — локальная проверка

Проверяет, что бот реально стартует и отвечает на этой машине. Блокирующий шаг pipeline.

## Шаги

### 1. Прочитать конфигурацию запуска

Прочитай секцию «Локальное тестирование» из `CLAUDE.md`: `start_cmd`, `stop_cmd`, `smoke_check`,
`required_env`, `notes`.

### 2. Проверить окружение

```powershell
Test-Path .env                       # если нет — скопировать из .env.example
Test-Path .venv\Scripts\python.exe   # если нет — сказать пользователю про python -m venv .venv
(Get-Command claude).Source          # claude должен быть в PATH
claude --version
```

- Если `.env` отсутствует — скопируй `.env.example` → `.env` и **предупреди пользователя**,
  какие переменные он должен заполнить вручную (`BOT_TOKEN`, `ADMIN_USER_IDS`).
  Без них бот не стартует — это не баг, останови проверку и скажи об этом.
- Если `claude` не найден — зафиксируй как предупреждение: бот стартует, но работает
  в режиме деградации (поиск по справочнику без ИИ).
- Проверь, не запущена ли уже задача Task Scheduler `TNVED_BOT`
  (`Get-ScheduledTask -TaskName TNVED_BOT -ErrorAction SilentlyContinue`) и не занят ли
  `data/bot.lock`. Если бот уже работает — останови его перед проверкой, иначе будет конфликт
  polling'а (Telegram отдаёт апдейты только одному потребителю).

### 3. Запустить

Запусти `start_cmd` в фоне (`run_in_background: true`), перенаправив вывод в
`logs/local-test-stdout.log`.

### 4. Дождаться готовности

Проверяй `logs/bot.log` до появления события `bot_started` (таймаут 60 с).
Если за 60 с события нет — считай проверку упавшей, приложи последние 50 строк лога.

### 5. Smoke-проверка

```powershell
.\.venv\Scripts\python.exe scripts\smoke_check.py
```

Скрипт проверяет: процесс жив, `claude` доступен, в БД есть активная версия справочника,
в логе нет `ERROR` за время запуска. Приложи его вывод.

**Ручная часть** (попроси пользователя выполнить и подтвердить, если тикет затрагивает
пользовательский сценарий):

- отправить боту `/start` → должно прийти приветствие с дисклеймером
- отправить «кофеварка капельная бытовая 900 Вт» → должен прийти код с уверенностью и альтернативами
- отправить фото любого товара → должно прийти описание с подтверждением
- отправить «труба» → должен прийти уточняющий вопрос с кнопками

### 6. Остановить

Останови процесс через `stop_cmd` (`Stop-Process -Id <PID>` по `data/bot.lock`).
Убедись, что `data/bot.lock` освобождён.

### 7. Записать результат

Сохрани отчёт в `reports/qa/local-test-<YYYY-MM-DD>.md`: команды, вывод, время старта,
результат smoke-проверки, ошибки из лога, ручные шаги и их результат.

## Вердикт

- ✅ **локальный запуск успешен** — бот стартовал, smoke прошёл, `ERROR` в логе нет
- ❌ **упал** — приложи лог и точную причину; pipeline останавливается, возврат к `/implement`

Никогда не помечай шаг успешным, если что-то не проверено — скажи прямо, что осталось непроверенным.
