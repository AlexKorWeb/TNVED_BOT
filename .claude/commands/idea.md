# /idea — требования и PRD

Вызови агента `analyst` для активного тикета.

1. Прочитай `docs/.active_ticket`. Если файла нет или он пуст — спроси у пользователя номер тикета
   и запиши его туда.
2. Передай агенту: номер тикета, его описание из `docs/tasklist/tickets.md`, аргументы команды
   (`$ARGUMENTS`), если они есть.
3. Агент создаёт `docs/prd/<ticket-id>.md`.

Не пиши код на этом шаге. Если требования расходятся с `docs/TZ.md` — покажи расхождение
пользователю и дождись решения.

Следующий шаг: `/research` (если код уже есть) или `/plan`.
