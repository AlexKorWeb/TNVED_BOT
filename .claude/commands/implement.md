# /implement — реализация

Вызови агента `implementer` для активного тикета.

**Предусловие:** план `docs/plan/<ticket-id>.md` существует и подтверждён пользователем.
Если подтверждения не было — сначала покажи план и спроси.

1. Перед изменением существующего кода — прогони его тесты и зафиксируй базовую линию.
2. Агент идёт по шагам плана, после каждого: `ruff check` → `mypy` → `pytest` затронутых тестов.
3. Тесты пишутся вместе с кодом. Обработка ошибок — в том же тикете, не «потом».
4. Не удалять и не перезаписывать файлы без бэкапа или подтверждения пользователя.
5. По завершении — обновить `CHANGELOG.md`.

Покажи пользователю diff перед коммитом.

Следующий шаг: `reviewer` (вызывается проактивно), затем `/test`.
