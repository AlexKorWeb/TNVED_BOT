# Безопасность — TNVED_BOT

Всегда активно. Ни одно правило отсюда не может быть «упрощено» ради краткости кода —
безопасность вне Decision Ladder.

## Trust boundary

Всё, что пришло от Telegram (текст, подпись к фото, файл, callback_data), — **недоверенные
данные**. Граница доверия проходит по `core/sanitize.py`. До неё данные не используются нигде:
ни в БД, ни в промте, ни в путях, ни в логах на уровне INFO.

## Защита от prompt-инъекций (7 слоёв, все обязательны)

1. **Санитизация:** длина ≤ 2000; удаление control-chars; нормализация NFKC; удаление zero-width
   (`U+200B–200F`, `U+2060`, `U+FEFF`) и bidi-override (`U+202A–202E`); отклонение ввода,
   где доля не-букв > 70 %.
2. **Нейтрализация маркеров:** `<user_data>`, закрывающие теги, тройные бэктики, `Human:`,
   `Assistant:`, `System:`, `[INST]`.
3. **Изоляция:** пользовательский текст попадает в промт только внутри `<user_data>…</user_data>`
   и передаётся через **stdin**, никогда в argv.
4. **Отсутствие полномочий:** `--allowedTools ""` на текстовых шагах; vision-шаг — изолированная
   временная папка с единственным файлом.
5. **Валидация выхода:** ответ модели принимается только как строгий JSON по pydantic-схеме;
   каждый код сверяется с `nomenclature` **и** со списком переданных кандидатов.
6. **Экранирование:** `parse_mode=HTML` + `html.escape()` на всём, что от модели или пользователя;
   markdown и ссылки из ответа модели вырезаются.
7. **Аудит:** каждый вызов ИИ пишется в `audit_log`; срабатывание фильтров — событие
   `injection_suspected`.

## Прочие векторы

| Вектор | Обязательная мера |
|---|---|
| SQL-инъекция | только параметризованные запросы; f-string в SQL запрещён |
| FTS5-инъекция | запрос из whitelist-токенов `[а-яa-z0-9]`; спецсимволы `" * : ^ - NEAR` экранированы |
| Shell-инъекция | `asyncio.create_subprocess_exec(*args)`; `shell=True` запрещён |
| Path traversal | имена файлов — UUID4; `Path.resolve()` + проверка родительского каталога |
| Вредоносный «файл-картинка» | magic bytes + `Pillow.verify()` + **обязательный ре-энкод в JPEG**; лимиты 10 МБ и 8000×8000 |
| Утечка секретов | `BOT_TOKEN` только в `.env`; маскирование в логах; `.env.example` без значений |
| Флуд | rate limit 20/час, 100/сутки на пользователя, 300/сутки глобально |
| Раскрытие внутренностей | пользователю — только текст + `error_id`; никаких путей, промтов, traceback |
| Неавторизованный доступ | middleware `auth` (whitelist) — **первый** в цепочке |
| Опасное удаление | джанитор удаляет только внутри `data/photos`, `data/backups`, `logs` — с проверкой пути |

## Инвариант классификации

**Ни один код ТН ВЭД не уходит пользователю без `db.nomenclature.verify_code()`.**
Новый код-путь без этой проверки — блокирующее замечание на ревью, независимо от того,
насколько «очевидно» код корректен.

## Ключи LLM

Проект не содержит и не читает LLM-ключей: обращение к ИИ только через локальный CLI `claude -p`.
Прямые запросы к `api.anthropic.com` или другому провайдеру запрещены. Если когда-либо
понадобится HTTP API — только через Cloudflare AI Gateway (`base_url` шлюза), никогда напрямую.

## При обнаружении уязвимости

Пометить место комментарием `# WARNING: <суть>`, сразу предложить и реализовать безопасную
альтернативу, сообщить пользователю. Небезопасный паттерн не реализуется, даже если о нём
попросили напрямую.

## Работа с файлами

Не удалять и не перезаписывать файлы без резервной копии или подтверждения пользователя.
Файлы с токенами и учётными данными (`.env`) считать read-only.
