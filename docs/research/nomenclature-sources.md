## Ограничения источника

- [ ] **Только уровень 10 знаков.** Отдельных строк для групп и позиций (2/4/6/8) нет.
      `parent_code` вычисляется усечением; строки-предки при необходимости синтезируются
      из общих префиксов `name_full`.
- [ ] **Нет доп. единицы измерения** — поле `unit` останется `NULL` в v1.
- [ ] **Нет примечаний к группам и разделам** — поле `notes` останется `NULL`. Это ослабляет
      применение ОПИ 1 и 6 моделью; компенсируется тем, что полный путь иерархии присутствует
      в наименовании.
- [ ] **Неофициальный источник** — коммерческий сервис, не ФТС и не ЕЭК. Приемлемо для личного
      справочного инструмента, но усиливает необходимость дисклеймера в каждом ответе.
- [ ] **Лицензия** — «предоставляется как есть, без каких-либо гарантий и обязательств».
      Для личного использования ограничений нет; перепубликация данных не предполагается.

## Особенности для импортёра (T-003)

1. Читать **вторую** вкладку (`ТНВЭД`). Первая — обложка; с неё брать дату актуальности
   и заявленное количество кодов, сверять с фактическим числом строк.
2. Разделитель `🠺` (U+1F83A) нормализовать в ` / ` при записи `name_full`; последний сегмент
   пути писать в `name`.
3. Наименования до 1111 символов — не обрезать при записи в БД; обрезать только при выводе
   пользователю.
4. Колонку `Тариф` сохранять в отдельное поле (задел под v2 — расчёт платежей). В ответе v1
   не использовать.
5. Колонку `Подробности` (везде строка «подробнее») отбрасывать.
6. Маппинг колонок оставить конфигурируемым — чтобы переход на официальную выгрузку не требовал
   переписывания импортёра.

## Обновление справочника

Ежедневная выгрузка означает, что данные не устареют, если периодически перекачивать файл.
Автоматизация обновления в объём v1 не входит — обновление вручную:

```powershell
Invoke-WebRequest -Uri 'https://www.tws.by/tws/tnved/download/excel' `
  -OutFile "data\nomenclature\tnved_tws_$(Get-Date -Format 'yyyy-MM-dd').xlsx"
python scripts\import_nomenclature.py "data\nomenclature\tnved_tws_$(Get-Date -Format 'yyyy-MM-dd').xlsx"
```

Импортёр обязан определять повторную загрузку того же файла по SHA-256 и требовать `--force`.
